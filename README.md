# ADNY Separador Clean

O ADNY Separador Clean recebe uma imagem e separa as cores da arte em canais para serigrafia. O resultado é exportado em PSD para revisão e preparo dos fotolitos.

[Baixar ADNY Separador Clean para Windows 64 bits](https://github.com/adnyestampa-dot/ADNY-Separador-de-canais/releases/download/v0.1.0/ADNY-Separador-Clean-Windows-x64.zip)

## Como usar

1. Extraia todo o ZIP e abra `ADNY Separador Clean.exe`. Mantenha a pasta `_internal` junto ao executável.
2. Abra a imagem no separador e salve o resultado em PSD.
3. Abra o PSD no Photoshop ou no PhotoCraft. Confira os canais, faça os microajustes necessários e prepare a retícula e as marcas de registro antes de imprimir os fotolitos.
