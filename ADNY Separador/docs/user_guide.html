ADNY Separador — Guia do usuário

Separador de canais para simulado serigráfico.

Interface para separação de cores na estamparia, com motor FAV8+ (Spot Process).

1. Abrir e separar

Arquivo > Abrir... (Ctrl+O) carrega a arte e separa automaticamente. Cada cor aparece na barra de separações embaixo e como caixa em Separações ativas na barra Main.

2. Separações ativas

As ferramentas de edição (Encharcar, Borracha, Editar > Excluir, Ajustar separações) só alteram as ativas. Use as caixas, Marcar todas e Desmarcar todas na barra Main.

3. Ferramentas

FerramentaUso
MoverArraste para deslocar a imagem.
ZoomClique para ampliar; Alt+clique ou botão direito para reduzir.
Laço / Laço poligonal / Seleção retangularSelecione uma área. Laço poligonal: clique nos vértices, duplo clique ou Enter para fechar.
Conta-gotasClique numa cor: seleciona pixels parecidos, marca a separação dominante na barra e mostra X/Y/Densidade na barra de status. Shift+clique soma à seleção.
EncharcarPinte para aumentar a densidade de tinta das separações ativas; segure Alt para aliviar. Cada traço vira um passo de Desfazer.
BorrachaPinte para apagar tinta das separações ativas. Cada traço vira um passo de Desfazer.

4. Menu Editar

  • Desfazer / Refazer (Ctrl+Z / Ctrl+Y).
  • Desmarcar seleção (Ctrl+D) e Inverter seleção (Ctrl+Shift+I): a seleção passa a ser a imagem inteira menos a anterior.
  • Excluir (Del): apaga a tinta das separações ativas dentro da seleção.
  • Impressora padrão... (Ctrl+E): impressora, mídia, resolução, meio-tom e filme gravados nas preferências.

5. Menu Separações

Realçar vermelho/laranja, Gerar marrom, Fundir cinza/roxo/turquesa, Criar base branca, Encaixe na mesa, Ajustar separações (Ctrl+J) e Ajuste automático. Tudo pode ser desfeito.

6. Exibir

Ampliar/Reduzir, Preencher janela, Ajustar à tela, Pixels reais e Igualar zoom (aplica o zoom da janela ativa a todas). Vistas Prova positiva / Tinta / Filme e Mostrar cor do tecido.

7. Impressão

Arquivo > Imprimir... (Ctrl+P) abre o Print Commander para saída dos filmes.
